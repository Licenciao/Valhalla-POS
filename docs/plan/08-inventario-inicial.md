## Conciliaciones necesarias antes de importar

Este inventario permanece como referencia provisional hasta verificar físicamente cantidades y costos. Se puede cargar claramente rotulado, pero no se usa para vender ni para reportes oficiales hasta conciliación y aprobación administrativa.

La regla aprobada para Valhalla 750 consume 0.750 L Ensamble, una botella de 750 ml y un corcho sintético. Mini 375 consume 0.375 L 1 Dest., una botella de 375 ml y un corcho de madera. El líquido usa el costo reportado de $80/L.
